Éditeur pixel art

Outil de production autonome — n'est chargé ni par le jeu, ni par le service worker. Édite des grilles compatibles avec la palette PAL de src/sprites.js ; le résultat s'exporte en JS prêt à coller dans le code du jeu. Pensé pour les portraits de héros, mais réutilisable tel quel pour les sprites de vaisseaux et, plus largement, tout élément pixel-art du jeu.
